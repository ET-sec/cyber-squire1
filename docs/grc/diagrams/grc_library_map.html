THE GOVERNANCE LIBRARY, MAPPED

Thirteen document families, 57 documents. The core plans are the spine: every other family either states a rule the plan implements, hands the plan a finding, or inherits from it. Read top to bottom and each family is legible by the time you reach it.

Core plans
3 documents
The spine. One system security plan holding 140 NIST 800-53 control rows, one plan of action holding 42 findings, one risk assessment behind them. Every other family cites a row of these three.
SSP_SYSTEM_SECURITY_PLAN.md, POAM_PLAN_OF_ACTION.md, RISK_ASSESSMENT.md, plus the scanner written auto ledger POAM_AUTO_FINDINGS.md, which is machine generated and counted separately
Framework crosswalks
3 documents
The same control set re-indexed for a reader who arrives holding a different framework: HIPAA Security Rule, SOC 2 with ISO 27001, and the handling spec that governs the data those two ask about. No new claim is made here.
HIPAA_SECURITY_RULE_CROSSWALK.md, HIPAA_EPHI_HANDLING.md, FRAMEWORK_CROSSWALK_SOC2_ISO27001.md
The plan implements the policies. The crosswalks re-index the plan. Neither adds a control, which is why they sit beside the spine rather than above it.
