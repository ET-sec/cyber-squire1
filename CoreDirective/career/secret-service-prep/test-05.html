SECTION C: Logic-Based Reasoning (21 through 30)

21. The vault opens IF AND ONLY IF BOTH (biometric verification AND keycard verification) succeed AND AT LEAST ONE of (supervisor code OR emergency override) is entered. On Tuesday the vault did NOT open. Which conclusion MUST follow?

  • A. Biometric verification failed and no supervisor code was entered.
  • B. Keycard verification failed and the emergency override also failed.
  • C. Both supervisor code and emergency override were not entered.
  • D. At least one clause failed: biometric, keycard, or both authorization codes.
  • E. The vault likely malfunctioned; no input failure can be inferred.

22. Seven packages (A, B, C, D, E, F, G) are inspected in a single-file line. Constraints: (1) A is inspected immediately before D; (2) F is inspected fifth; (3) C is inspected at some point before F; (4) B is inspected last; (5) E is not inspected first. Which order is consistent with ALL constraints?

  • A. A, D, C, E, F, G, B
  • B. D, A, C, E, F, G, B
  • C. A, C, D, E, F, G, B
  • D. A, D, E, G, C, F, B
  • E. E, A, D, C, F, G, B
