## CHANGES FROM v1 (and WHY)

### Structure changes:
| Element | v1 (Old) | v2 (New) | Science |
|---------|----------|----------|---------|
| Headline | "You're about to spend $300..." (question) | "Stop Guessing. Master the 200-301." (command) | Commands create urgency (Cialdini, Authority principle). Matches Net+ format. |
| Word count | ~600 words (wall of text) | ~250 words (scannable) | Cognitive Load Theory (Sweller 1988): Less = easier decisions. Nielsen: users read 20% of page content. |
| Pain section | 3 paragraphs | 2-3 sentences | Shorter agitation → faster to "the solution" (PAS framework) |
| Feature list | 12+ flat bullets, no bold labels | 3 bullets with bold labels x 2 sections | Rule of 3 (Miller 1956): Groups of 3 are optimal for processing |
| Section headers | "What's inside:" (generic) | "The Mastery Infrastructure" (premium) | Premium language increases perceived value (Ariely, Predictably Irrational) |
| Jeremy IT Lab ref | "Accountability Matrix aligned to Jeremy's IT Lab Days 1 through 63" | REMOVED | Trademark risk. Replaced with DoK Framework (original IP). |
| Closing | "Your $300 exam voucher deserves a real plan." | Builder creds + battle-tested certs | Social proof via authority (Cialdini principle #5) |
| Retake cost | $300 | $330 | Updated to accurate 2025-2026 Cisco pricing |
| Career hook | None | "move toward the CCNP" | Future-pacing: readers visualize next step (NLP technique) |

### What was removed and why:
- **"Who this is built for" section** — Net+ doesn't have it. The pain paragraph already qualifies the reader.
- **"The guarantee" section** — Moved to implied trust (7-day guarantee on cover image). Reduces cognitive load.
- **"What changes when you start using this" section** — Redundant with "The Mastery Infrastructure." Transformation is embedded in the bullets.
- **12+ feature bullet list** — Distilled to 3 highest-impact features per section. Rule of 3 > dump list.
- **"Jeremy's IT Lab" reference** — Trademark risk. The DoK Framework is YOUR original IP — lean into it.
