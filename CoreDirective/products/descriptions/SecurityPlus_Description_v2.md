## CHANGES FROM v1 (and WHY)

### Structure changes:
| Element | v1 (Old) | v2 (New) | Science |
|---------|----------|----------|---------|
| Headline | "You're about to spend $404..." (question) | "Stop Guessing. Master the SY0-701." (command) | Commands create urgency. Matches Net+ format exactly. |
| Word count | ~650 words | ~250 words | Cognitive Load Theory: Less content = faster purchase decision |
| Pain section | 3 long paragraphs | 2-3 sentences | PAS framework: agitate faster, solve faster |
| Feature list | 13 flat bullets | 3 bold bullets x 2 sections | Rule of 3 (Miller 1956) |
| Section headers | "What's inside:" | "The Mastery Infrastructure" | Premium language = higher perceived value |
| "Who this is built for" | Full paragraph | REMOVED | Pain paragraph already qualifies the reader |
| "The guarantee" | Full paragraph | Implied (cover image + Gumroad refund) | Reduces cognitive load |
| Career hook | None | "move toward the CySA+ and CASP+" | Future-pacing |
| Domain names | Not listed | Listed in parentheses | Specificity builds trust (Heath & Heath, Made to Stick) |
| Closing | "Your $404 exam voucher deserves a real plan" | Builder creds + battle-tested certs | Social proof via authority |

### What was removed and why:
- **"This is not another PDF" sequence** — Defensive positioning. Net+ doesn't do this. Lead with what it IS.
- **"What changes when you start using this" section** — Embedded in bullet descriptions now.
- **"325+ acronyms" in description** — Moved to cover image only. Description focuses on methodology, not feature dump.
- **12+ flat feature bullets** — Distilled to 3 per section. Specific numbers live on the cover, methodology lives in the description.
- **"If you have ADHD" standalone line** — ADHD is now a bullet point benefit, not a separate pitch.
